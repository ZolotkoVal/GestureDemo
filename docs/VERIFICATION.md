## Что реально запускалось

**Не запускались повторно успешные сценарии.** Тесты вызывают реальные сохранённые composable-функции через Compose rule на устройстве; test harness не добавляет экран выбора в приложение. Проверки опираются на пиксели captureToImage, текст семантики и синтетические touch events, а не на изменение переменных в обход обработчиков.

1. `08-device-tests.log`: первый запуск 7 тестов. Шесть PASS, один FAIL (второй цвет ClickDemo проверялся во время ripple). Это не успешный полный прогон.
2. `09-rotation-red-click-green.log`: исправлена только синхронизация цветового теста с завершением ripple (500 мс реального времени), код ClickDemo не изменялся. ClickDemo PASS. Новый rotation-тест закономерно FAIL на версии без rotationZ.
3. `09-rotation-green.log`: только rotation, **OK (1 test)**.
4. `10-translation-red.log`: только новый translation, ожидаемый FAIL на версии без translationX/Y.
5. `10-translation-green.log`: только translation после реализации, **OK (1 test)**.

Итого **9 уникальных сценариев с подтверждённым PASS**, агрегировано программно в `evidence/summary.json`. Полный единый прогон всех девяти на финальном APK не заявляется. Масштабирование проверено на этапе 8, rotation на этапе 9, translation на финальном этапе; ранее успешные проверки не повторялись. Ранние `*-red.log` в `_lab08_evidence` означают ошибки компиляции тестов из-за ещё отсутствующей функции, **не runtime TDD-assertion**. Реальный runtime RED/GREEN получен для поворота и перемещения.

## Сборка и lint

Этапы 1–9 имеют отдельные успешные Gradle-логи и коммиты. На этапе 10 `assembleDebug` и `assembleDebugAndroidTest` завершились, но общая команда завершилась ошибкой lint: неэкранированное двоеточие Windows SDK-пути в локальном `local.properties`. Исправлен только этот исключённый из Git файл проекта.

Следующий lint вернул закэшированную старую ошибку. Принудительно повторён **только** `lintAnalyzeDebug` (`--rerun`) с генерацией отчёта; сборки приложений и успешные тесты не повторялись. `10-lint-refreshed.log` — BUILD SUCCESSFUL. Первоначальные FAIL-логи сохранены.

Финальный lint: **0 Error, 0 Fatal, 8 Warning**; также есть подсказки AutoboxingStateCreation. Предупреждения касаются DataExtractionRules, GradleDependency, IconLocation, MissingApplicationIcon; suppressions/обновления зависимостей не применялись ради косметики. Простые mutableStateOf из лекции сохранены.

`stages.json` хранит десять APK/коммитов. Последний этап назван `10-lint-refreshed`: его APK собран предыдущей командой `10-translation`, затем принят после исправления lint. Это не отдельная повторная сборка. Финальный APK SHA-256 и фото-хеш — в summary.json.
